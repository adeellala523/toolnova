How to Remove Duplicates in Excel (5 Methods)

ToolNova Guides · 7 minute read

A mailing list with the same address three times. A sales export where one customer appears on five rows. A class register pasted together from two sheets. Duplicates creep into every spreadsheet, and Excel has five different ways to get rid of them — each best at a different job. This guide works through all five with a real example, explains when to use which, and covers the invisible traps (trailing spaces, text-vs-number) that make Excel insist two identical-looking values are different.

The Worked Example

Every method below runs on the same list: 12 email addresses in cells A2:A13, with 4 of them repeated. The correct answer is 8 unique addresses and 4 removed — keep that in mind as a check, because a method that reports a different number is telling you it found a difference you can't see.

ana@example.com · ben@example.com · ana@example.com · cara@example.com · dan@example.com · ben@example.com · emma@example.com · finn@example.com · cara@example.com · grace@example.com · ana@example.com · henry@example.com

Unique (8): ana, ben, cara, dan, emma, finn, grace, henry. Removed (4): the 2nd and 3rd ana, the 2nd ben, the 2nd cara.

Method 1: The Remove Duplicates Button (Fastest)

This is the method for most jobs — one click, no formulas, done in seconds.

Step 1 — click any cell inside your list (or select the whole range A2:A13).

Step 2 — go to the Data tab and click Remove Duplicates.

Step 3 — tick "My data has headers" if your first row is a header (Email, Name…) rather than data. If you forget this, Excel will treat your header as a value — and if a data row happens to match the header text, the header itself gets deleted.

Step 4 — choose which columns define a duplicate. Tick only Email if one repeated email means the whole row is a duplicate. Tick several columns and Excel only removes rows where all ticked columns match.

Step 5 — click OK. Excel reports what it did: on our example, "4 duplicate values found and removed; 8 unique values remain."

Two things to know: it keeps the first occurrence and deletes the later ones, and it is permanent — the rows are gone, so work on a copy of the sheet if the original matters. Undo (Ctrl+Z) works immediately afterwards, but only until you save and close.

Method 2: The UNIQUE Function (Keeps the Original)

If you want the clean list without touching the original — or a list that updates itself when the source changes — use UNIQUE. It needs Microsoft 365 or Excel 2021 or later.

In an empty cell, type: =UNIQUE(A2:A13)

The 8 unique addresses spill out below the formula, in the order they first appear: ana, ben, cara, dan, emma, finn, grace, henry.

The result is live: add a new address to the source list and it appears in the clean list; fix a typo and the clean list follows. The trade-off is that the spilled cells are formula results, not typed values — if you need a standalone list to paste elsewhere, copy the spill range and use Paste Special → Values first. To sort the result at the same time, wrap it: =SORT(UNIQUE(A2:A13)).

Method 3: Advanced Filter (Clean Copy Elsewhere)

Advanced Filter is the old-school answer and the only one of the five that works on every Excel version, including older ones without UNIQUE.

Step 1 — click any cell inside your list.

Step 2 — go to Data → Advanced (in the Sort & Filter group).

Step 3 — choose "Copy to another location", set the "Copy to" box to an empty cell, and tick "Unique records only".

Step 4 — click OK. The 8 unique addresses appear at the new location; the original list is untouched.

Choose "Filter the list, in-place" instead and Excel hides the duplicate rows rather than copying anything — useful for a quick look, but the hidden rows are still there, so don't use it when you need a genuinely clean list.

Method 4: Power Query (For Lists You Clean Every Week)

If the same messy export lands on your desk every Monday, Power Query turns the cleanup into a one-click repeat instead of a weekly chore.

Step 1 — click inside the list, then Data → From Table/Range and confirm the table dialog.

Step 2 — in the Power Query editor, select the column and go to Home → Remove Rows → Remove Duplicates.

Step 3 — click Close & Load. The clean table lands on a new sheet.

Next week, paste the new export over the old source table and click Data → Refresh All — the same steps run again automatically. Power Query also has a "Remove Errors" and "Trim" step in the same editor, so trailing spaces (the number-one cause of surviving duplicates) can be cleaned in the same pass. The cost is setup time: for a one-off list, Method 1 is faster.

Method 5: A COUNTIF Helper Formula (Works on Any Excel)

When you need to see which rows are duplicates before deleting anything — or you're on an old Excel without UNIQUE — a helper column does the job.

In B2, type: =IF(COUNTIF($A$2:A2,A2)>1,"Duplicate","Unique") and copy it down to B13.

The formula counts how many times the current value has appeared so far — the $ locks the start of the range while the end moves down with the row. First occurrences say "Unique"; the 2nd ana, 2nd ben, 2nd cara and 3rd ana say "Duplicate". Filter column B for "Duplicate" and delete those rows, or filter for "Unique" and copy what remains.

The $A$2:A2 expanding range is the whole trick: without the $ on the start, the count restarts on every row and every value looks unique. The same COUNTIF idea works as a conditional-formatting rule if you only want the duplicates highlighted rather than listed.

Find Duplicates First: Conditional Formatting

Before removing anything, it's worth looking at what Excel thinks is duplicated — especially when the count comes back different from what you expected. Select the range, then Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values, pick a colour, and every repeated value lights up. In our example, all three anas, both bens and both caras highlight — 7 cells in total, which is the 4 removed rows plus the 3 first occurrences they duplicate. If a value you know is repeated doesn't light up, you have an invisible difference: check the next section.

Why Duplicates Survive: The Invisible Differences

Excel compares values exactly, and "exactly" includes things your eyes skip:

  • Trailing spaces. "ana@example.com " with a space at the end is a different value from "ana@example.com". This is the most common cause by far. Fix it with =TRIM(A2) in a helper column, or Power Query's Trim step, before removing duplicates.
  • Case doesn't matter — but only in Excel. Remove Duplicates and UNIQUE are both case-insensitive: "Ana@example.com" and "ana@example.com" count as the same value. If case matters to you, the COUNTIF helper is case-insensitive too — you need an EXACT-based array formula instead.
  • Numbers stored as text. The number 42 and the text "42" look identical in a cell but are different values to Excel. Convert with Text to Columns or by multiplying by 1 in a helper column.
  • Extra columns selected. If you tick Name as well as Email in the Remove Duplicates dialog, a row only counts as a duplicate when both match — so "ana@example.com / Ana" and "ana@example.com / A. Smith" both survive. Tick only the column that defines the duplicate.
  • Filtered or hidden rows. Remove Duplicates works on the visible data it can see; clear filters first, or the hidden rows keep their duplicates.
  • Merged cells. Merged cells block Remove Duplicates outright. Unmerge first (Home → Merge & Center → Unmerge Cells).

Which Method Should You Use?

One-off cleanup, original can go: Method 1, Remove Duplicates — fastest, nothing to learn.

Original must stay, or the list keeps changing: Method 2, UNIQUE — live, but needs Microsoft 365 / Excel 2021+.

Old Excel, or a clean copy in a new spot: Method 3, Advanced Filter — works everywhere.

Same messy export every week: Method 4, Power Query — set it up once, refresh forever.

You need to inspect before deleting: Method 5, COUNTIF helper — shows every duplicate first.

A note on Google Sheets, since the question comes up constantly: Sheets has the same idea under Data → Data cleanup → Remove duplicates, and =UNIQUE(A2:A13) works there too. The steps differ in name only — the traps (trailing spaces, text-vs-number) are identical.

Mistakes to Avoid

  • Running Remove Duplicates on the only copy. It deletes rows permanently. Duplicate the sheet first — it takes two seconds and has saved more data than any other habit in this guide.
  • Forgetting "My data has headers". Your header row gets treated as a value, and if any data row matches it, the header is deleted with the duplicates.
  • Ticking every column in the dialog. A row only counts as a duplicate when all ticked columns match. Tick only the column that defines the duplicate.
  • Trusting your eyes over TRIM. Trailing spaces are invisible and are the top reason duplicates "don't work". Clean first, deduplicate second.
  • Pasting a UNIQUE spill as formulas. The spilled cells are live formula results. Copy → Paste Special → Values before sending the list anywhere else.
  • Deleting "Duplicate" rows while a filter is on. Hidden rows stay hidden — clear the filter and check the count (8 unique, 4 removed in our example) before calling the job done.

Frequently Asked Questions

How do I remove duplicates in Excel?
Select your data, go to the Data tab and click Remove Duplicates. Tick 'My data has headers' if the first row is a header, choose which columns to check, and click OK. Excel deletes every repeated row after the first occurrence and tells you how many duplicates it removed and how many unique values remain.

How do I remove duplicates in Excel but keep the first occurrence?
That is exactly what Remove Duplicates does by default: it keeps the first time a value appears and deletes the later copies. The UNIQUE function works the same way — =UNIQUE(A2:A13) returns each value once, in the order it first appears.

How do I remove duplicates in Excel without deleting data?
Use a method that writes the clean list somewhere new instead of deleting rows. Type =UNIQUE(A2:A13) in an empty column, or use Data → Advanced Filter with 'Copy to another location' and 'Unique records only' ticked. Your original list stays untouched.

Why is Excel Remove Duplicates not working?
The usual causes are invisible differences: a trailing space makes 'ana@example.com ' a different value from 'ana@example.com', a number stored as text differs from the same number stored as a number, and merged cells or a filter hiding rows can block the tool. Clean the data with TRIM first, check the cell formats match, unmerge cells and clear filters, then run it again.

How do I remove duplicates in Excel using a formula?
For modern Excel (Microsoft 365 or Excel 2021 and later), type =UNIQUE(A2:A13) in an empty cell and the clean list spills out below it. On older Excel, add a helper column with =IF(COUNTIF($A$2:A2,A2)>1,"Duplicate","Unique"), copy it down, filter for 'Duplicate' and delete those rows.

How do I find duplicates in Excel before removing them?
Select the range, then go to Home → Conditional Formatting → Highlight Cells Rules → Duplicate Values. Every repeated value lights up in the colour you choose, so you can see what will be removed — and spot the near-duplicates (trailing spaces, different cases) before you commit.

How do I remove duplicate rows based on one column only?
In the Remove Duplicates dialog, untick every column except the one that defines a duplicate — for example, untick everything except Email. Excel then deletes any row whose email repeats, even if the other columns in that row are different. Be careful: the whole row is deleted, not just the email cell.
