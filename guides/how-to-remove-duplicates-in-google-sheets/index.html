How to Remove Duplicates in Google Sheets (5 Methods)

ToolNova Guides · 7 minute read

A mailing list with the same address three times. A form-response sheet where one person submitted five times. A class register pasted together from two sheets. Duplicates creep into every spreadsheet, and Google Sheets has five different ways to get rid of them — each best at a different job. This guide works through all five with a real example, explains when to use which, and covers the invisible traps (trailing spaces, text-vs-number) that make Sheets insist two identical-looking values are different.

The Worked Example

Every method below runs on the same list: 12 email addresses in cells A2:A13, with 4 of them repeated. The correct answer is 8 unique addresses and 4 removed — keep that in mind as a check, because a method that reports a different number is telling you it found a difference you can't see.

ana@example.com · ben@example.com · ana@example.com · cara@example.com · dan@example.com · ben@example.com · emma@example.com · finn@example.com · cara@example.com · grace@example.com · ana@example.com · henry@example.com

Unique (8): ana, ben, cara, dan, emma, finn, grace, henry. Removed (4): the 2nd and 3rd ana, the 2nd ben, the 2nd cara.

Method 1: Data Cleanup → Remove Duplicates (Fastest)

This is the method for most jobs — a few clicks, no formulas, done in seconds.

Step 1 — select the range to check (A2:A13 in our example, or the whole table).

Step 2 — go to the Data menu, then Data cleanup, then Remove duplicates. (Google's help pages sometimes give the shorter path Data → Remove duplicates — look there if your menu doesn't show Data cleanup.)

Step 3 — tick "Data has header row" if your first row holds column names (Email, Name…) rather than data. The box is off by default, so if you forget it, your header gets compared as if it were a data row — and if a data row happens to match the header text, the header itself gets deleted.

Step 4 — choose which columns define a duplicate. Tick only Email if one repeated email means the whole row is a duplicate. Tick several columns and Sheets only removes rows where all ticked columns match.

Step 5 — click Remove duplicates, then OK on the status window. On our example it reports "4 duplicate rows removed; 8 unique rows remain."

Two things to know: it keeps the first occurrence and deletes the later ones, and it is permanent — the rows are gone, so work on a copy of the sheet if the original matters. Undo (Ctrl+Z, or Cmd+Z on a Mac) works immediately afterwards. One more limit: the tool lives in the desktop menu, so on a phone or tablet open the sheet in a desktop browser instead — the Sheets mobile app doesn't offer it.

Method 2: The UNIQUE Function (Keeps the Original)

If you want the clean list without touching the original — or a list that updates itself when the source changes — use UNIQUE. It works in every Google Sheets, no add-on needed.

In an empty cell, type: =UNIQUE(A2:A13)

The 8 unique addresses spill out below the formula, in the order they first appear: ana, ben, cara, dan, emma, finn, grace, henry.

The result is live: add a new address to the source list and it appears in the clean list; fix a typo and the clean list follows. The trade-off is that the spilled cells are formula results, not typed values — if you need a standalone list to paste elsewhere, copy the spill range and use Paste Special → Paste values only first. To sort the result at the same time, wrap it: =SORT(UNIQUE(A2:A13)). UNIQUE has two extra tricks worth knowing: =UNIQUE(A2:A13,FALSE,TRUE) returns only the values that appear exactly once — the repeats vanish entirely, which is handy for finding one-off entries — and =UNIQUE(B2:D5,TRUE) compares columns instead of rows, for data arranged sideways.

Method 3: A COUNTIF Helper Formula (Works on Any Sheet)

When you need to see which rows are duplicates before deleting anything, a helper column does the job.

In B2, type: =IF(COUNTIF($A$2:A2,A2)>1,"Duplicate","Unique") and copy it down to B13.

The formula counts how many times the current value has appeared so far — the $ locks the start of the range while the end moves down with the row. First occurrences say "Unique"; the 2nd ana, 2nd ben, 2nd cara and 3rd ana say "Duplicate". Filter column B for "Duplicate" and delete those rows, or filter for "Unique" and copy what remains.

The $A$2:A2 expanding range is the whole trick: without the $ on the start, the count restarts on every row and every value looks unique. The same COUNTIF idea works as a conditional-formatting rule if you only want the duplicates highlighted rather than listed — see "Find Duplicates First" below.

Method 4: QUERY Counts Every Value (Best for Auditing a Big List)

Sometimes you don't want the clean list yet — you want to know how bad the problem is. QUERY counts every distinct value in one shot.

In an empty cell, type: =QUERY(A2:A13,"select A, count(A) where A is not null group by A label A 'Email', count(A) 'Count'",0)

The result is a small table: each email once, with its count beside it. ana shows 3, ben and cara show 2, the other five show 1. Any row with a count above 1 is a duplicate — and the total of (count − 1) across all rows is the 4 duplicates to remove.

The trailing ,0 matters: it tells QUERY the range has no header row, so it doesn't mistake your first email for a column name. The "where A is not null" part keeps blank cells out of the count. This method shines on big lists — a thousand-row export becomes a short table of the values that actually repeat, which is exactly the audit you want before running Method 1.

Method 5: Trim Whitespace + Cleanup Suggestions (Fix the Ones That Won't Go)

The fifth method isn't a deduplicator at all — it's the fix for the duplicates that survive the first four. Most "Remove duplicates didn't work" complaints come down to invisible spaces, and Sheets has a one-click fix built into the same menu.

Step 1 — select the range, then go to Data → Data cleanup → Trim whitespace. It strips leading spaces, trailing spaces and double spaces inside cells. In our example, "ana@example.com " with a trailing space becomes "ana@example.com" — and only then does Remove duplicates recognise it as the same address.

Step 2 — while you're in the menu, try Data → Data cleanup → Cleanup suggestions. Sheets scans the sheet and flags issues it can fix itself — stray spaces, inconsistent formats, blank rows — and applies the fixes you approve. It's the closest Sheets comes to a "clean this up for me" button.

The order matters: trim first, deduplicate second. Running Remove duplicates on untrimmed data leaves the spaced copies behind, and nothing in the report tells you why.

Find Duplicates First: Conditional Formatting

Before removing anything, it's worth looking at what Sheets thinks is duplicated — especially when the count comes back different from what you expected. Select the range, then go to Format → Conditional formatting, pick "Custom formula is" and enter =COUNTIF($A$2:$A$13,A2)>1, then choose a fill colour. In our example, all three anas, both bens and both caras highlight — 7 cells in total, which is the 4 removed rows plus the 3 first occurrences they duplicate. If a value you know is repeated doesn't light up, you have an invisible difference: check the next section.

Why Duplicates Survive: The Invisible Differences

Sheets compares values exactly, and "exactly" includes things your eyes skip:

  • Trailing spaces. "ana@example.com " with a space at the end is a different value from "ana@example.com". This is the most common cause by far. Fix it with Data → Data cleanup → Trim whitespace (Method 5) before removing duplicates.
  • Case doesn't matter — but only to the built-in tools. Remove duplicates treats "Ana@example.com" and "ana@example.com" as the same value — Google says cells count as duplicates even when their letter case differs. If case matters to you, the COUNTIF helper is case-insensitive too; use an EXACT-based helper instead: =IF(SUMPRODUCT(--EXACT($A$2:A2,A2))>1,"Duplicate","Unique").
  • Numbers stored as text. The number 42 and the text "42" look identical in a cell but are different values to Sheets. Convert with =VALUE(A2) in a helper column, or select the cells and use Format → Number.
  • Extra columns selected. If you tick Name as well as Email in the Remove duplicates dialog, a row only counts as a duplicate when both match — so "ana@example.com / Ana" and "ana@example.com / A. Smith" both survive. Tick only the column that defines the duplicate.
  • Filtered or hidden rows. Remove duplicates works on the data it can see; clear filters first (Data → Remove filter, or turn off any filter views), or the hidden rows keep their duplicates.
  • The header box was left unticked. "Data has header row" is off by default. Leave it off with a header row present and your header is treated as a value — and if a data row matches it, the header is deleted with the duplicates.

Which Method Should You Use?

One-off cleanup, original can go: Method 1, Remove duplicates — fastest, nothing to learn.

Original must stay, or the list keeps changing: Method 2, UNIQUE — live, and it works in the mobile app too.

You need to inspect before deleting: Method 3, COUNTIF helper — shows every duplicate first.

Auditing a big list before cleaning it: Method 4, QUERY — one table of every value and its count.

Duplicates that refuse to go: Method 5, Trim whitespace + Cleanup suggestions — fix the invisible differences, then run Method 1 again.

A note on Excel, since the question comes up constantly: Excel has the same idea under Data → Remove Duplicates, and =UNIQUE(A2:A13) works there too — we cover all five Excel methods in our How to Remove Duplicates in Excel guide. The steps differ in name only — the traps (trailing spaces, text-vs-number) are identical.

Mistakes to Avoid

  • Running Remove duplicates on the only copy. It deletes rows permanently. Duplicate the sheet first (right-click the sheet tab → Duplicate) — it takes two seconds and has saved more data than any other habit in this guide.
  • Forgetting "Data has header row". The box is off by default. Your header row gets treated as a value, and if any data row matches it, the header is deleted with the duplicates.
  • Ticking every column in the dialog. A row only counts as a duplicate when all ticked columns match. Tick only the column that defines the duplicate.
  • Trusting your eyes over Trim whitespace. Trailing spaces are invisible and are the top reason duplicates "don't work". Clean first, deduplicate second.
  • Pasting a UNIQUE spill as formulas. The spilled cells are live formula results. Copy → Paste Special → Paste values only before sending the list anywhere else.
  • Deleting "Duplicate" rows while a filter is on. Hidden rows stay hidden — clear the filter and check the count (8 unique, 4 removed in our example) before calling the job done.

Frequently Asked Questions

How do I remove duplicates in Google Sheets?
Select your data, go to Data → Data cleanup → Remove duplicates. Tick 'Data has header row' if the first row holds column names, choose which columns to check, and click Remove duplicates. Sheets deletes every repeated row after the first occurrence and tells you how many duplicates it removed and how many unique values remain.

How do I remove duplicates in Google Sheets without deleting data?
Use a method that writes the clean list somewhere new instead of deleting rows. Type =UNIQUE(A2:A13) in an empty cell and the 8 unique values spill out below it. Your original list stays untouched, and the clean list updates itself if the source changes.

How do I remove duplicates in Google Sheets but keep the first occurrence?
That is exactly what Data cleanup → Remove duplicates does by default: it keeps the first time a value appears and deletes the later copies. The UNIQUE function works the same way — =UNIQUE(A2:A13) returns each value once, in the order it first appears.

Why is Google Sheets Remove duplicates not working?
The usual causes are invisible differences: a trailing space makes 'ana@example.com ' a different value from 'ana@example.com', a number stored as text differs from the same number stored as a number, and a filter hiding rows can block the tool. Clean the data with Data → Data cleanup → Trim whitespace first, check the cell formats match and clear filters, then run it again.

How do I remove duplicates in Google Sheets using a formula?
For a clean list that stays live, type =UNIQUE(A2:A13) in an empty cell. To see which rows are duplicates before deleting anything, add a helper column with =IF(COUNTIF($A$2:A2,A2)>1,"Duplicate","Unique"), copy it down, filter for 'Duplicate' and delete those rows.

How do I find duplicates in Google Sheets before removing them?
Select the range, then go to Format → Conditional formatting, pick 'Custom formula is' and enter =COUNTIF($A$2:$A$13,A2)>1 with a fill colour. Every value that appears more than once lights up, so you can see what will be removed — and spot the near-duplicates (trailing spaces, different cases) before you commit.

How do I count how many times each value appears in Google Sheets?
Use QUERY: =QUERY(A2:A13,"select A, count(A) where A is not null group by A label A 'Email', count(A) 'Count'",0). It lists every value once with its count beside it, so any row with a count above 1 is a duplicate. The trailing ,0 tells QUERY the range has no header row.

How do I remove duplicates in Google Sheets on mobile?
The Sheets mobile app does not offer the Remove duplicates tool. Open the spreadsheet in a desktop browser on your phone or tablet instead — Data → Data cleanup → Remove duplicates is there — or wait until you are at a computer. The =UNIQUE formula does work in the mobile app if you only need a clean copy.
