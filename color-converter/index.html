One Color, Three Languages

Screens don't care what you call a color; they mix light. But the tools of design and development describe that mixing in three different dialects, and work constantly forces translation between them. HEX (like #0E7C86) is the compact six-character code of web design — three pairs of hexadecimal numbers for red, green and blue. RGB states the same mix as ordinary numbers from 0 to 255: rgb(14, 124, 134). HSL re-describes it the way humans actually think — a hue around the color wheel (0–360°), saturation as a percentage, and lightness as a percentage: hsl(185, 81%, 29%).

Why keep all three? Because each is best at something. HEX is shortest for copying into code and brand guidelines. RGB is what most software, from image editors to CSS color pickers, displays natively. HSL is the one you can actually reason with: need a darker version of a color? Drop the lightness. A muted one? Lower the saturation. Try doing that in HEX, where every change is hexadecimal guesswork. This converter shows all three side by side, updates as you pick, accepts a typed HEX when you already have one, and copies any value with a single click.

A Worked Example

The classic reference color: pure red. In HEX it's #FF0000. In RGB it's rgb(255, 0, 0) — maximum red, no green, no blue. In HSL it's hsl(0, 100%, 50%): hue 0 (red sits at the top of the wheel), full saturation, and halfway lightness.

Now use HSL's superpower. Keep hue 0 and saturation 100%, drop lightness to 25% and you've designed maroon. Raise lightness to 75% and you get a soft pastel pink-red. Same hue family, three coordinated colors — the practical way designers build palettes, and it took ten seconds because HSL separates “which color” from “how strong” and “how light”.

When to Use Each Format

  • HEX: CSS, design handoffs, brand guidelines, anywhere brevity wins. Add two more digits (like #0E7C86CC) and it carries transparency too — that's the alpha channel, 0–255 written in hex.
  • RGB / RGBA: when you need transparency in CSS (rgba(14, 124, 134, 0.5)), when matching values shown in photo editors, or when a tool asks for the three channels separately.
  • HSL / HSLA: building hover states, shades and tints (adjust lightness ±10%), accessible variants, and design systems where a whole palette derives from one hue.
  • Named colors (“teal”, “crimson”): fine in conversation, unreliable in production. Always pin the actual code — one person's teal is another's turquoise.

Common Mistakes to Avoid

  • Guessing a color from a screenshot. Compression and screen settings shift values. A color that “looks like” #0E7C86 may really be #12767E — close on screen, visibly off when placed side by side in a design. Always convert from the source value.
  • Forgetting that HEX pairs are hexadecimal. The “86” in #0E7C86 is 134 in decimal, not 86. That's exactly the conversion the RGB panel exists to do for you.
  • Designing shades by random tweaking. Random darker colors drift in hue and look muddy. Adjust lightness in HSL and the family resemblance is guaranteed.
  • Ignoring contrast. A beautiful color can be unreadable text on the wrong background. Light pastel text on white fails accessibility guidelines — check important text/background pairs against WCAG contrast ratios (4.5:1 for body text).

Frequently Asked Questions

How do HEX codes work?

A HEX code is three numbers written in base 16, one per channel: red, green, blue. Each pair runs 00 (none) to FF (full, 255 in decimal). #FF0000 is full red; #000000 is black; #FFFFFF is white. A leading # marks it as a color code.

What is the difference between RGB and HSL?

RGB describes a color as amounts of red, green and blue light. HSL describes the same color by hue (position on the color wheel), saturation (intensity) and lightness. They're two coordinate systems for the identical color — this page converts between them losslessly.

How do I make a color darker or lighter?

Convert it to HSL and change only the lightness: lower for darker, higher for lighter, keeping hue and saturation fixed. It's the reliable way to create matching shades and hover states without the color turning muddy.

What does the A in RGBA or HSLA mean?

Alpha — transparency. It runs from 0 (fully transparent) to 1 (fully opaque) in RGBA/HSLA, or 00–FF as an extra pair in 8-digit HEX. A shadow or overlay color is usually a semi-transparent black, like rgba(0, 0, 0, 0.25).

Can I enter a color I found as RGB and get its HEX?

Yes — the panels stay in sync. Adjust via the picker or the HEX field and all three formats update together; there's always a copy button for the one your destination needs.

Why does my color look different on another screen?

Screens vary in calibration, brightness and color gamut, and some colors in the HEX/RGB space sit outside what a given display can reproduce. The code is the ground truth; the rendering is an approximation. For brand-critical work, check on a calibrated monitor.
