HEX, RGB and HSL — When to Use Each

HEX (#7C5CFF) is the shorthand of the web: six hexadecimal digits encoding red, green and blue. Designers share brand colors in HEX because it is short and unambiguous. RGB spells the same mix out as three numbers from 0–255, and its cousin RGBA adds an alpha channel for transparency — essential for overlays and shadows. HSL thinks like a human: pick a hue (the color family on a 0–360° wheel), then saturation (how vivid) and lightness (how bright). Need a darker button hover state? Keep the hue, drop lightness by 10% — that is why CSS custom properties and design systems increasingly start from HSL.

Frequently Asked Questions

What is the difference between HEX, RGB and HSL?

HEX is a compact code (#7C5CFF), RGB mixes red/green/blue from 0–255, and HSL uses hue, saturation and lightness — easier for humans to adjust.

How do I find a color’s HEX code?

Pick the color with the swatch, or paste a HEX in the field — all other formats appear instantly.

Which format should I use in CSS?

All work. HEX is shortest, RGB(A) supports transparency, HSL is best for generating shades and tints.

Do the values work in Figma or Photoshop?

Yes — copy and paste them into any design tool’s color panel.
