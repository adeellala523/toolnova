How HEX to RGB Conversion Works

A hex color code is just three numbers written in hexadecimal (base 16) instead of decimal (base 10) — one number each for red, green and blue, each ranging from 00 (none of that color) to FF (full strength). Converting is a matter of reading the code as three pairs and translating each pair from base 16 to base 10.

  1. Drop the # if there is one. It is only a marker; #FF5733 and FF5733 are the same color.
  2. Expand shorthand. A 3-digit code doubles each digit: #F53 becomes #FF5533.
  3. Split into three pairs. FF5733 splits into FF (red), 57 (green) and 33 (blue).
  4. Convert each pair to decimal. FF = 255, 57 = 87, 33 = 51 — so the result is rgb(255, 87, 51).

A Worked Example

A designer hands a developer the brand teal #0e7c86 and asks for a semi-transparent version for a button hover. First, convert: the pairs 0e, 7c and 86 become rgb(14, 124, 134) — 0e is 14, 7c is 124, 86 is 134 in decimal. Paste it above and the converter confirms exactly that, with hsl(185, 81%, 29%) alongside.

Then the transparency step writes itself: take the RGB numbers and add an alpha value, giving rgba(14, 124, 134, 0.5) for a 50% teal overlay. That is the whole reason RGB matters even when you already have the hex code — CSS opacity lives in the rgba() form, and it needs these three numbers. A second check with a warm accent, #FF5733, gives rgb(255, 87, 51); and the shorthand #F53 expands to #FF5533, which is rgb(255, 85, 51).

Tips for Using HEX and RGB Together

  • Use RGBA for overlays, shadows and hovers. rgba(14, 124, 134, 0.5) tints without hiding what sits underneath; a flat hex color cannot do that.
  • Keep the hex code as the source of truth. Hex is shorter to store in a style guide, and RGB is derived from it in one step — never maintain two separate lists that can drift apart.
  • Check the swatch, not just the numbers. A typo in one hex digit can shift a color subtly (7c vs 7d is invisible in numbers, visible on screen). The live swatch above catches it at a glance.
  • Remember the shorthand rule. #F53 is not a different color family from #FF5533 — it is the same color written shorter. Expanding first avoids wrong conversions.
  • Copy the CSS, don't retype it. One transposed digit turns a brand teal into a stranger's blue. The copy buttons above paste the exact value.

Common Mistakes to Avoid

  • Forgetting that hex pairs are base 16, not base 10. FF is not 99 — it is 255. Reading hex pairs as ordinary numbers is the most common conversion error.
  • Mixing up the channel order. #FF5733 is red 255, green 87, blue 51 — not the other way round. Swapping red and blue turns an orange into a blue.
  • Using a 3-digit code as if it were 6 digits. #F53 read as three single values gives nonsense; expand it to #FF5533 first.
  • Pasting RGB numbers into a hex field. rgb(255, 87, 51) and #FF5733 describe the same color but are different notations — a field expecting hex will reject the rgb() form. Convert first, then paste.

Frequently Asked Questions

How do I convert HEX to RGB?

Split the hex code into three pairs of digits — one pair each for red, green and blue — and convert each pair from hexadecimal (base 16) to decimal (base 10). For example, #FF5733 splits into FF, 57 and 33, which are 255, 87 and 51 in decimal, so the RGB value is rgb(255, 87, 51). The converter above does this instantly for any code you paste in.

What is the RGB value of #0e7c86?

rgb(14, 124, 134). The hex pairs 0e, 7c and 86 convert to 14, 124 and 134 in decimal — a deep teal. Paste #0e7c86 into the converter above to see it with its RGBA and HSL values and a live swatch.

Can I convert a 3-digit hex code like #F53 to RGB?

Yes. A 3-digit hex code is shorthand: each digit is doubled to make the 6-digit code. #F53 becomes #FF5533, which converts to rgb(255, 85, 51). The converter above accepts 3-digit codes and expands them automatically.

Do I need the # symbol when converting HEX to RGB?

No. #FF5733 and FF5733 mean the same color — the # is just a marker that says "this is a hex code". The converter above accepts codes with or without it, with or without spaces.

Why would I need RGB when I already have the HEX code?

Because CSS transparency needs RGB. You cannot write a semi-transparent hex color as #FF573380 in older browsers, but rgba(255, 87, 51, 0.5) works everywhere — and it needs the RGB numbers. Design tools and app code also commonly ask for RGB, so converting is a daily step for designers and developers.

How do I convert RGB back to HEX?

Convert each RGB number (0–255) to a two-digit hexadecimal number and join them with a # in front. For example, rgb(255, 87, 51) becomes #FF5733, because 255 is FF, 87 is 57 and 51 is 33 in hex. The converter above has an RGB-to-HEX section that does this for you.

Is my color data uploaded or stored anywhere?

No. The conversion happens entirely in your browser and nothing you type leaves your device. You can convert brand colors or unreleased palette codes here without anything being sent or saved anywhere.
