WiFi QR Code Generator

Let guests join your WiFi by scanning a code — no typing the password, no spelling it out loud, no typos. Fill in your network details, print the code, and stick it on the wall. Free, instant, 100% local in your browser · no sign-up.

Why a WiFi QR Code Beats Reading the Password Out Loud

Every café owner, Airbnb host, office manager and homeowner knows the ritual: a guest asks for the WiFi, you recite a 16-character password full of capitals, digits and symbols, they mistype it twice, and you both lose a minute. A printed WiFi QR code ends that ritual. The guest points their phone camera at the code, taps "Join", and they're online — no typing, no misheard characters, no password written on a sticky note for the whole room to read.

It also solves a quieter problem: the password itself stays out of sight. Guests never see the actual characters, so they can't pass them on by accident — or by text message to someone you never invited onto the network. And because the code is static, it works forever: print it once for the guest room, the café table, or the office lobby, and it keeps working until you change the network name or password.

How a WiFi QR Code Works

  1. Type your network name exactly as it appears on the router — WiFi names are case-sensitive, so "CafeLuna" and "cafeluna" are different networks.
  2. Pick the security type. Almost every modern router uses WPA/WPA2; only choose WEP for genuinely old equipment, and "No password" only for a truly public network.
  3. Enter the password (or tick "Hidden network" if your router doesn't broadcast the name), then click "Generate WiFi QR Code".
  4. Test it with your own phone camera before printing: it should offer to join the network immediately. Then download the PNG and print it wherever guests will see it.

Behind the scenes, the code stores a short text string in the standard format phones understand — for example WIFI:T:WPA;S:CafeLuna_Guest;P:coff33time!;H:false;; — with special characters escaped so the phone reads the name and password exactly. A Worked Example

A small café's guest network is called CafeLuna_Guest, password coff33time!, WPA2 security. The owner types those details here, generates the code at 1024 × 1024, downloads the PNG, and prints it on a small framed card for each table: "Free WiFi — scan to join."

Result: new customers connect in about five seconds instead of flagging down staff and misspelling the password. Staff stop repeating the password all day, guests stop asking, and the password itself is never displayed in plain text. When the café eventually changes the password, the owner generates a fresh code and swaps the cards — a two-minute job.

Tips for WiFi QR Codes That Connect First Time

  • Copy the network name exactly — including capitals, spaces and symbols. A single wrong character means the phone tries to join a network that doesn't exist. Double-check against the router label or your phone's WiFi settings.
  • Test on both an iPhone and an Android phone if you can. Both read WiFi codes from the built-in camera, but older Android models sometimes need the code scanned from Google Lens instead.
  • Print at 1024 × 1024 for anything on paper. Small downloads look fine on screen but go soft when printed; the large size keeps the squares crisp on cards, frames and posters.
  • Keep the quiet zone. The white border around the code is part of the code — don't crop it off and don't print on a dark or busy background.
  • Put the code where the phone will actually be. Table cards, the reception desk, the guest-room nightstand — not behind glass, not above head height, not in dim light.

Common Mistakes to Avoid

  • Typing the password from memory instead of copying it. Passwords with look-alike characters (0/O, 1/l) are easy to get wrong. Copy it from the router label or your saved network settings.
  • Forgetting the hidden-network tick. If your router hides its name and you skip the box, phones will look for a visible network and fail to connect.
  • Sharing a code for your private network with the public. A printed code in a shop window gives everyone in range a free connection. Use a separate guest network for public codes and keep your main network private.
  • Using an open network for a home or office. "No password" codes are fine for a genuinely public hotspot, but at home or work they leave every device on the network unprotected.

Frequently Asked Questions

How do I create a QR code for my WiFi?

Type your network name (SSID) above, pick the security type (usually WPA/WPA2), enter the password, and click Generate. Print the code or show it on a screen — anyone who scans it joins the network without typing anything.

Do guests need a special app to scan a WiFi QR code?

No. On iPhones (iOS 11 and later) and most Android phones, the built-in camera app reads the code and offers a Join button. No app download, no extra step.

Is my WiFi password safe in a QR code?

The password is encoded inside the code itself — anyone who scans it can join, so only share the printed code with people you would give the password to anyway. Nothing is uploaded or stored here: the code is generated entirely in your browser.

Does a WiFi QR code work for a hidden network?

Yes — tick the 'Hidden network' box above. The code then carries a flag telling the phone the network is not broadcasting its name, so it connects instead of searching for a visible network.

What if my network has no password?

Choose 'No password (open network)' as the security type. The code will connect guests straight to the open network. Only do this for genuinely public networks, since open WiFi has no encryption.

Does a WiFi QR code expire?

No. The code is static — it keeps working as long as your network name and password stay the same. If you change the WiFi password, generate and print a new code.

What size should I print a WiFi QR code?

For a table card or a framed sign scanned from arm's length, about 2.5 cm (1 inch) square is enough. For a poster scanned from a few steps away, go bigger — a useful rule is 10:1, so a code scanned from 1 meter away should be at least 10 cm wide. Download at 1024 × 1024 for print.
