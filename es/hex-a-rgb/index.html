Conversor de HEX a RGB

Convierte cualquier código de color HEX a RGB, RGBA y HSL al instante, con muestra de color en vivo y conversión inversa de RGB a HEX. Para diseñadores y desarrolladores que necesitan el mismo color en dos formatos distintos.

rgb(14, 124, 134)RGB
rgba(14, 124, 134, 1)RGBA
hsl(185, 81%, 29%)HSL
#0E7C86HEX (normalizado)

Inverso: RGB → HEX

Por qué necesitas RGB si ya tienes HEX

HEX y RGB describen el mismo color, pero no sirven para lo mismo. HEX es compacto y es el formato habitual en paletas de diseño y guías de marca. RGB es el que necesitas cuando el color debe variar: sobre todo para la transparencia. En CSS, un color semitransparente se escribe con rgba(), y no existe equivalente directo en HEX clásico. Por eso, para superponer un color sobre una foto o crear un degradado suave, primero hay que convertirlo.

HSL, el tercer formato que muestra esta herramienta, es el que usan muchos diseñadores para razonar sobre el color: tono (qué color es), saturación (qué intenso es) y luminosidad (qué claro u oscuro es). Cambiar la luminosidad de un HSL es más intuitivo que tocar tres números RGB.

Cómo usar el conversor

  1. Escribe o pega un código HEX, con o sin almohadilla (#0e7c86 o 0e7c86): el resultado se actualiza al instante.
  2. O elige un color con el selector: verás la muestra y todos los formatos a la vez.
  3. Copia el valor RGB o la regla CSS completa con un clic.
  4. Para el camino inverso, escribe los valores R, G y B (de 0 a 255) en la sección «Inverso: RGB → HEX».

Ejemplo práctico: el verde azulado de ToolNova

El color principal de este sitio es #0e7c86. Al convertirlo, la herramienta muestra rgb(14, 124, 134), hsl(185, 81%, 29%) y el HEX normalizado #0E7C86. Para una superposición semitransparente del mismo color sobre una imagen, basta con añadir el canal alfa: rgba(14, 124, 134, 0.5).

Otros dos casos útiles: #FF5733 (un coral intenso) se convierte en rgb(255, 87, 51), y el código abreviado #F53 se expande primero a #FF5533 y luego a rgb(255, 85, 51). Cada par hexadecimal es un número en base 16: 0e es 14, 7c es 124 y 86 es 134.

Consejos para trabajar con colores

  • Usa el selector para explorar. Mueve el color hasta que la muestra se parezca a lo que buscas y copia el formato que necesites, sin adivinar códigos.
  • Copia la regla CSS completa. El botón «Copiar CSS» entrega el valor listo para pegar en tu hoja de estilos, sin reescribir nada a mano.
  • Guarda el HEX normalizado. La herramienta muestra el código en mayúsculas y con almohadilla: es la forma canónica para guardarlo en una guía de marca.
  • Recuerda que solo RGBA tiene transparencia. Si necesitas un color al 50%, usa rgba() con alfa 0.5: rgb() no admite transparencia.

Errores comunes que debes evitar

  • Escribir caracteres que no son hexadecimales. Solo valen los dígitos 0–9 y las letras a–f. Un «g» o una «z» hacen que el código no sea válido, y la herramienta te avisará.
  • Confundir el orden RGB. El primer par es rojo, el segundo verde y el tercero azul: #FF0000 es rojo puro, no azul.
  • Esperar transparencia de rgb(). Sin el canal alfa no hay transparencia: para eso está rgba().
  • Olvidar la almohadilla en CSS. En una hoja de estilos el HEX lleva # delante; el conversor acepta el código con o sin ella, pero tu CSS la necesita.

Preguntas frecuentes

¿Cómo se convierte HEX a RGB?

Se divide el código en tres pares hexadecimales y cada par se pasa a decimal: en #0e7c86, 0e es 14 (rojo), 7c es 124 (verde) y 86 es 134 (azul). El resultado es rgb(14, 124, 134).

¿Qué es RGBA?

Es RGB más un canal alfa que indica la opacidad, de 0 (totalmente transparente) a 1 (totalmente opaco). rgba(14, 124, 134, 0.5) es el mismo verde azulado al 50% de opacidad.

¿Puedo usar códigos HEX de 3 dígitos?

Sí. Cada dígito se duplica: #F53 se expande a #FF5533 y equivale a rgb(255, 85, 51). Es una abreviatura habitual en CSS.

¿HEX y RGB representan exactamente el mismo color?

Sí. Son dos notaciones del mismo color: HEX lo escribe en base 16 y RGB en tres valores decimales. Convertir de uno a otro no cambia el color.

¿Por qué el conversor muestra también HSL?

Porque muchos diseñadores piensan en tono, saturación y luminosidad al ajustar un color. HSL hace intuitivo, por ejemplo, aclarar u oscurecer un color sin cambiar su tono.

¿Tengo que escribir la almohadilla (#)?

No. El conversor acepta el código con o sin almohadilla (#0e7c86 o 0e7c86). En tu CSS, eso sí, el HEX debe llevarla delante.
